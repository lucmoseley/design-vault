## 1. Sources checked

| Row | Record | Source opened, and what it says |
|---|---|---|
| BTN-34 | `vault.bottom-safe-area` | web.dev, Learn Forms (2021): the submit button "may be behind the browser toolbar"; use `env()`. MDN `env()`: the safe-area insets are above 0 where "toolbars or dynamic keyboards" take viewport space; the page never names `viewport-fit`. MDN viewport meta: with `viewport-fit=cover` "It's highly recommended to use the safe area inset variables". MDN `<length>`: with `lvh` content "might get hidden when browser interfaces expand"; `dvh` can resize content while scrolling. web-features: `svh`, `lvh`, `dvh` Baseline widely available 2025-06-05. |
| BTN-59 | `vault.expanded-state` | WAI-ARIA APG Menu Button: `aria-haspopup` "menu or true"; `aria-expanded` true when shown, "set to false" when hidden (not removed). APG Disclosure: the same. M3 split button unread, with no GitHub equivalent. |
| BTN-73 | `vault.act-on-release` | WCAG 2.2 SC 2.5.2 (A, Dec 2024 edition): No Down-Event, Abort or Undo, Up Reversal, Essential; keypad emulation counts as essential. Understanding (updated Sep 2025): "the click event ... is an example of an implicit up-event", device-independent. |
| MOT-112 | `vault.slow-update` | Media Queries Level 4, `update` (CRD 19 Feb 2026): `none` for print, `slow` for "E-ink screens or severely under-powered devices", `fast` for screens where CSS animations can be used. web.dev, Learn Design, "Media features" (Aug 2025): transitions inside `(update: fast)`. web-features `update`: Baseline low 2023-09-18, high 2026-03-18. |
| NAV-1 | `vault.badge-name` | UK Ministry of Justice Design System, Notification badge (Oct 2025): `visuallyHiddenText` required, a "Descriptor for screenreaders to give context to the number". Bootstrap 5.3 Badge: without context badges "may seem like random additional words or numbers"; example `99+ <span class="visually-hidden">unread messages</span>`. material-components-android BadgeDrawable: plural-aware content descriptions. Atlassian Badge says nothing on announcement. |
| NAV-48 | `vault.progress-name` | WAI-ARIA 1.2 (Jun 2023) progressbar: "Accessible Name Required: True"; omit `aria-valuenow` when indeterminate. MDN progressbar role: "An accessible name is required". MDN `<progress>`: "Text placed between the element's tags is not an accessible label". material-web Progress: `aria-label="Download progress"`. |
| NAV-75 | `vault.live-region-ready` | USWDS Alert (guidance updated Aug 2026): "Don't visually hide alert messages and then make them visible when they are needed." MDN Live regions: "Start with an empty live region"; "include them in the initial markup"; `role="alert"` is announced even when injected. APG Alert: alerts present before page load are not announced. |
| NAV-77 | `vault.status-no-focus` | WCAG 2.2 SC 4.1.3 (AA): status messages presented "without receiving focus". Angular Material v12 Snackbar: "does not move focus"; offer the action another way; no duration when it has an action. Flutter 3.37 (2025): a snackbar with an action stays until used, which Flutter says matches M3. |
| NAV-144 | `vault.cookie-banner` | GOV.UK Cookie banner, Option 1: no banner for essential cookies alone, "However, you must tell users", by a cookies page linked from the footer. ICO, "Guidance on the use of storage and access technologies" (finalised 29 Apr 2026): after the Data (Use and Access) Act 2025, five exceptions, strictly necessary, statistical and appearance among them; the last two need "clear and comprehensive information" and "an easy way to object". The ICO page the ledger job named says it is out of date. EU ePrivacy art. 5(3): strictly necessary storage exempt, no analytics exception. |
| PAG-56 | `vault.top-tasks` | NN/g, Nielsen (11 May 2002), guideline 4: "clear starting points for the main 1–4 tasks". McGovern, A List Apart (21 Apr 2015): top tasks "usually less than 10, often less than five", found by a ranked survey. Checks `function-questions.md:145`. |
| TXL-66 | `vault.list-marker` | Butterick, "Bulleted and numbered lists": `ul`, "Don't type them manually"; bullets "noticeable, but no bigger"; "Simple geometric dingbats are better than pictorial ones". USWDS Icon list (Dec 2024): the icon "should only reinforce the text", `aria-hidden`; the standard list for running text. MDN `content`: generated content may not be announced. No W3C, GOV.UK or MDN page says emoji markers are read by name; Oregon State University's accessibility guidance does ("White heavy check mark Task one"). Refactoring UI has no free page and is not cited. Checks `design-rules-census.md:164` (D7, emoji bullets). |
| COL-55 | `vault.imagery-colour` | Apple HIG Color, read through its `.md` (changed 16 Dec 2025): "Consider how artwork and translucency affect nearby colors"; "Avoid using similar colors in control labels if your app has a colorful background". material-components-android Color: content-based colour from "album artwork, a brand logo, or a video tile". Checks `past-design-rejections.md:61` (B11), whose quote is the founder's on lucmoseley/mmm-infra#8, comment 6018689130. |
| COL-107 | `vault.vibrating-edge` | MDN, "Colors and luminance": pure red and pure blue touching "may 'shimmer'". Adobe Spectrum, "Using color": high hue contrast at "near-equal saturation or lightness" gives chromostereopsis; "Use static white or static black components". Checks `brand-palette.md:45`; `:274` (no safe lightness gap) stays open, so the record looks at any pair under §1.2's 3:1 rendered. |
| COL-108 | `vault.colour-in-place` | Chevreul, tr. Butterick, "Presentations": a pale grey read against white, "simultaneous contrast". Checks `brand-palette.md:35`. |
