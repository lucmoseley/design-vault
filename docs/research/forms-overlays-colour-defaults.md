# Forms, overlays, colour and feel defaults: source checks (#279)

The source checks behind tier 0 jobs ranks 17–20 and 31 of the coverage ledger: carry-design-feel, carry-adopt-or-build, colour-defaults, overlays-defaults and surfaces-defaults. Sources were opened on 19 Oct 2026; a row says where one could not be.

## 1. Sources checked

| Row | Record | Source opened, and what it says |
|---|---|---|
| MOT-10 | `vault.motion-frequency` | Atlassian Motion, "Tone down motion for frequent experiences": hover, press and list items "should use minimal, near-instant transitions"; "If someone will trigger this motion dozens of times a day, keep it under 150ms." IBM Carbon Motion: productive motion for tasks; "Reserve expressive motion for occasional, important moments." Freiberg, "Interaction Design" (Jul 2023), Frequency & Novelty: a command menu opened "hundreds of times a day" makes its animation a "cognitive burden". Checks `design-feel.md:152`. |
| OTH-17 | `vault.delight-frequency` | Taylor, "Family Values" (8 Jul 2024): "Delight tends to increase as the frequency of feature usage decreases." Carbon as above. Checks `design-feel.md:152`. |
| PAG-67 | `vault.element-count` | NN/g, Fessenden, "Aesthetic and Minimalist Design" (24 Jan 2021), heuristic 8: "Every extra unit of information in an interface competes with the relevant units of information"; a design that meets it is "not obligated to be minimalist". Checks `design-feel.md:150`: Reinecke and Gajos, CHI 2014 (abstract, Harvard copy): 2.4 million ratings from nearly 40,000 people; the colourfulness and visual complexity found most appealing differ by group, Russians preferring lower complexity. That line ties density to complexity and complexity to taste, not to a count; the record's count rule rests on NN/g. VisAWI's paper returned 403. |
| FRM-7 | `vault.one-thing-per-page` | GOV.UK Service Manual, "Structuring forms": "Start by splitting the form across multiple pages with each page containing just one thing"; "User research will tell you when you can merge pages together." USWDS, Complete a complex form: "Only show questions on one micro-topic at a time." Baymard, cart abandonment: "a one-page checkout with 30 form fields is often worse than a three-step checkout with well-designed forms". Atlassian Form usage, read to 100k of its 114k characters, has no rule on splitting. Checks `adopt-or-build.md:184` (adopt GOV.UK question pages). |
| FRM-8 | `vault.questions-per-page` | GOV.UK Question pages: "Start by asking one question per page"; "If you need to ask for multiple related things on a page, use a statement as the heading." Checks `adopt-or-build.md:184`. |
| FRM-29 | `vault.question-heading` | GOV.UK "Labels, legends and headings": "When you're asking just one question on a page, you can make the question the page's heading"; set the label or legend as the heading "(except if you're asking more than one question on the page)", so screen reader users hear it once. Checks `adopt-or-build.md:184`. |
| STA-63 | `vault.error-summary-focus` | GOV.UK Error summary: "move keyboard focus to the error summary", which GOV.UK Frontend does itself since a Feb 2025 change; "Put the error summary at the top of the `main` container", below breadcrumbs or a back link "but above the `<h1>`". Checks `adopt-or-build.md:184`. |
| PAG-32 | `vault.brand-distinct` | Ehrenberg-Bass Institute, Romaniuk, "Brands of distinction": an asset must be "unique", one that "only evokes the one brand", and "famous"; "Of these two, uniqueness is most important"; an element famous but not unique is to be avoided. The book (OUP 2018) and its publisher's page were not readable (403). Checks `adopt-or-build.md:193` and `design-coverage-gaps.md:168`. Fame is not carried: it is measured by surveying category buyers. CXL's article, the row's own source, returned 403. |
| COL-105 | `vault.colour-pair` | WCAG 2.2 failure F24: specifying a foreground colour without a background colour, or the reverse, fails 1.4.3, 1.4.6 and 1.4.8; the background may be set on an ancestor. |
| COL-12 | `vault.image-fallback-colour` | MDN, Backgrounds and borders: "you should also specify a `background-color` that will allow the text to be legible if the image does not load." F24: a background image sets the background, and its contrast is checked in case images are not displayed. |
| COL-99 | `vault.color-scheme` | MDN `color-scheme` (last modified 21 Jul 2026): the browser matches the canvas, scrollbars and "other interaction UI", form controls and "other browser-provided UI"; declare it on `:root` and in a `<meta name="color-scheme">` before any CSS, against "unwanted screen flashes". web.dev's theming page, the row's other source, was not opened. |
| COL-104 | `vault.caption-colours` | W3C WebVTT §7: cue `color` "rgba(255,255,255,1)", cue background "rgba(0,0,0,0.8)", font "5vh sans-serif". 47 CFR 79.103(c) (Cornell LII): apparatus lets the viewer set caption character colour, opacity, size, font, background colour and opacity, edges and window colour. web.dev, Learn CSS, Pseudo-elements: `::cue` styles the captions of a `<video>`; it gives no colour advice. eCFR redirected to a bot check and was read through Cornell. |
| SUR-3 | `vault.hr-break` | HTML Living Standard, `hr`: "a paragraph-level thematic break", or a separator between option groups in a `select`; "There is no need for an hr element between the sections themselves". Butterick, "Rules and borders": "Never make rules and borders out of repeated typographic characters"; use the CSS border properties. |
| NAV-106 | `vault.nav-order` | W3C Understanding SC 3.2.3 (AA): repeated navigation occurs "in the same relative order each time they are repeated" "unless a change is initiated by the user"; inserted or removed items keep the order. Atlassian Menu, the row's other source, was not opened. |
| NAV-115 | `vault.submenu-close` | WAI-ARIA APG Menubar: Tab will "close all menus and submenus"; Right Arrow on an item with no submenu "Closes the submenu and any parent menus"; Escape closes "the menu that contains focus". web.dev, Popover and dialog, Nested popovers: "Closing a popover also closes all popovers after it in the stack." |
| NAV-139 | `vault.interruptions` | W3C Understanding SC 2.2.4 (AAA): "Interruptions can be postponed or suppressed by the user, except interruptions involving an emergency"; example, a preference that postpones all updates to the end of the session. |
| NAV-151 | `vault.dialog-name` | WAI-ARIA APG Dialog (Modal): role dialog, aria-modal true where outside content is blocked, a name from aria-labelledby on a visible title or from aria-label. MDN `<dialog>` (last modified 2 Oct 2026): exposed like role="dialog"; opened by `showModal()` it has aria-modal true. Material 3 Dialogs, the row's own source, renders only by script and was not read. |
| NAV-236 | `vault.hover-content` | W3C Understanding SC 1.4.13 (AA): dismissible "without moving pointer hover or keyboard focus" unless it reports an input error or covers nothing; hoverable; persistent until the trigger is removed, it is dismissed or it is no longer valid. #277 landed the same rule first as `vault.hover-content` for NAV-240, so NAV-236 joined that record rather than a second one. |
| VG-NEW-1 | `vault.menu-ellipsis` | Apple HIG Menus (read through its JSON data, the page renders by script): "Append an ellipsis to a menu item's label when the action requires more information before it can complete." Microsoft Windows UX guidelines, Menus (written for Windows 7, updated Jul 2026): an ellipsis marks a command "that needs additional information (including a confirmation)", not every command that opens a window; "Menu items that display submenus never have an ellipsis". Siemens iX, Progress updates: "Use horizontal ellipses (…) after the verb without a space"; none for time remaining; "Change verb form without ellipses when possible in buttons with loading spinners". The Microsoft Style Guide's ellipses page says nothing on progress labels. |

## 2. Choices the sources left open

- **Answerers.** NAV-115, NAV-139 and NAV-236 were tagged `gate`. Each is behaviour a render cannot show, so their records are answered by `code` until a driven-interaction probe exists (#258 §Scripts lists hover, opening overlays and press as probes not yet built).
- **2.2.4 is AAA.** The house floor is AA (`vault.wcag-aa`); #216 ruled NAV-139 filled, so the record holds the house to it for interruptions only, ranked below a project's rules.
- **PAG-32.** `vault.brand-layer` already placed distinctiveness in the brand layer; the new record adds Romaniuk's uniqueness test against competitors, so the row cites both.
