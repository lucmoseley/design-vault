# Rule records: content

What a page says and in what order: proof and trust among it. The form is [rules.md](../rules.md)'s.

- applies-when: any; every testimonial, review, client logo, count, rating, award, press mention and usage figure the asset shows
- question: Is every piece of proof the asset shows the project's own, from a source it can name, with none invented?

- writes: proof
- yields-to: none
- source: for testimonials and reviews, the FTC's rule 16 CFR Part 465 and the UK's DMCC Act 2024, Schedule 20 paragraph 13; for logos, counts, press and usage figures, the founder's House DNA and design-critique; strength: law for testimonials and reviews, founder ruling for the rest
- era: timeless
- owner: vault
- stage: function
- target: Show only the project's own proof, each piece from a source it can name.
- reasons: design-critique/references/first-visit-trust.md#the-checklist
- ledger: IMG-173, NEW1-76, NEW1-77, NEW3-64, NEW3-65, PAG-76, PAG-86
- status: live

### vault.element-count
- applies-when: any; every element on the page
- question: Does every element on the page carry information or a feeling the visitor needs for the page's task, with nothing irrelevant or rarely needed competing with it, rarely used features shown on demand, and nothing the task needs removed to look minimal?
- answered-by: whole-page
- writes: element count
- yields-to: none
- source: NN/g, Fessenden, "Aesthetic and Minimalist Design" (2021), Nielsen's heuristic 8: "Interfaces should not contain information which is irrelevant or rarely needed", and "Every extra unit of information in an interface competes with the relevant units of information"; a design that meets it is "not obligated to be minimalist" (as read Oct 2026); strength: published usability heuristic
- era: timeless
- owner: vault
- stage: function
- target: Give the page only the elements its task needs, show rarely used features on demand, and keep everything the task needs however busy it looks.
- reasons: design-critique/references/house-principles.md#every-element-earns-its-place
- ledger: PAG-67
- status: live
